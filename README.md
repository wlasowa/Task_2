# Task_2

## API-автотесты для учебного сервиса «Stellar Burgers»

## Описание проекта

- urls.py — адрес сервиса и эндпоинты
- data.py — тексты сообщений API
- helpers.py — генерация случайных строк и данных юзера
- api/user_api.py — методы API для юзера (регистрация, логин, изменение, удаление)
- api/order_api.py — методы API для заказов (создание, получение списка, ингредиенты)
- conftest.py — фикстуры: создание/удаление юзера, получение ингредиента
- tests/
  - test_create_user.py — создание юзера (успешное и негативные)
  - test_login_user.py — логин юзера (успешное и негативные)
  - test_change_user_data.py — изменение данных юзера (с/без авторизации)
  - test_create_order.py — создание заказа (с/без авторизации, без ингредиентов, неверный хеш)
  - test_get_user_orders.py — получение заказов юзера (с/без авторизации)
